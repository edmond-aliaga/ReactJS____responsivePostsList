This project is built in React js, and is about a simple list of posts. It is fully responsive and automatically adapts to screens of phones, tablets and computers with monitors of different dimensions.

Except the basic packages, additional packages are also needed, such as: react-dom, uuid, and packages derived from Material UI (@emotion/react, @emotion/styled, @mui/icons-material, @mui/material). In the index.html file you can find the link that serves to download a font that is used here.

For practical reasons, I have not attached the node_modules folder here, but you can get all the necessary information about the packages you need using the npm install command in the project terminal.



Happy coding!
